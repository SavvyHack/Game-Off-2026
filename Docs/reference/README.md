# Reference art

Reference images used as look targets live in this folder **locally only**. They are other artists' work, so
they are ignored by git and must not be committed or shipped. Ask a teammate for the files.

| File | Used for |
|---|---|
| `pod-reference.png` | Cutaway concept of a one-person pod: layout and mood target for the drone pod level. |

What we take from `pod-reference.png`: a cramped cylindrical hull with heavy ring bulkheads, a cockpit with a
seated pilot and cyan screen glow at one end, a blue sofa with wall monitors, a tall glass tube, a bunk with
green bedding, thrusters at the far end, and a coupling ring. The in-game art must be our own.
